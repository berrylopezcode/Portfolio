# Sour — Roblox Lua / Luau Portfolio

Upload these files into the same `Portfolio` folder as your GitHub Pages site:
- index.html
- styles.css
- script.js

Your repository should look like:

Portfolio/
├── index.html
├── styles.css
├── script.js
└── images/
    ├── animations.png
    ├── energy.png
    ├── profile.png
    └── remotes.png

The HTML already references the images with these exact relative paths:
- images/animations.png
- images/energy.png
- images/profile.png
- images/remotes.png

Keep the spelling and `.png` extensions exactly the same.

The project images are clickable and open in a larger preview.

Before publishing, replace `YOUR_EMAIL@example.com` in index.html with your real email address.
